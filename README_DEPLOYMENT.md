## 📦 Quick Deploy (30 minutes)

### 1. Push to GitHub
```bash
git add .
git commit -m "Production ready"
git push origin main
```

### 2. Deploy to Railway
- Go to https://railway.app
- Deploy from GitHub
- Copy variables from `RAILWAY_ENV_VARS.txt`
- Paste Google credentials JSON

### 3. Deploy to Vercel
- Go to https://vercel.com
- Deploy from GitHub (root: `frontend`)
- Add `VITE_API_URL` with Railway URL

### 4. Update CORS & Test
- Update `CORS_ORIGINS` in Railway
- Generate demo data
- Test all features
